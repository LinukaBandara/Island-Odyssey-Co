# Island Odyssey Co.

Island Odyssey Co. is a premium Sri Lanka travel-planning website focused on destinations, curated tours, travel inspiration, and lead-generation journeys.

## Stack
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Next Image / Sharp

## Experience
- Destination discovery across Sri Lanka
- Filterable tour packages
- Reviews and travel journal
- Itinerary interaction and enquiry flows
- Responsive mobile navigation
- Privacy and terms pages
- SEO metadata, Open Graph cards, sitemap, and robots.txt
- Cookie-consent-gated analytics
- Security headers and production image optimization

## Local development
npm install
npm run dev

Copy .env.example to .env.local and configure the public runtime values required for deployment. Do not commit environment files containing secrets.

## Status
The site is structured as a production-ready marketing experience; form submission integrations can be connected to the final CRM or email provider when required.
